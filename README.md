# 🌧️ Rainwater Harvesting Analysis

A modern, interactive web dashboard built for **Environmental Studies (EVS) — Semester 7** to analyze and visualize rainwater harvesting data.

## 🚀 Tech Stack

- **React 18** with TypeScript
- **Vite** — fast dev & build tooling
- **Three.js / React Three Fiber** — 3D tank visualization
- **Recharts** — data charts & graphs

## ✨ Features

- 📊 **Interactive Dashboard** — real-time charts and KPIs
- 🧮 **Calculator View** — rainwater potential & savings estimator
- 🌿 **3D Tank Graphic** — animated water tank visualization
- ⚙️ **Settings Panel** — configurable parameters
- 🌙 **Dark Mode** — sleek dark-themed UI

## 🛠️ Getting Started

```bash
# Install dependencies
npm install

# Start the dev server
npm run dev

# Build for production
npm run build
```
